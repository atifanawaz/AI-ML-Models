# Logistic Regression - Classification Model using Scikit-learn

This notebook demonstrates a basic implementation of **Logistic Regression** using Python and Scikit-learn.

## Dataset
- **Pima Indians Diabetes Dataset**  
  A binary classification problem to predict whether a patient has diabetes based on diagnostic measurements (e.g. glucose level, BMI, age, etc.).

## Features of This Notebook

- Load and clean the dataset
- Handle missing or zero values in key columns
- Scale numerical features using `StandardScaler`
- Split data into training and testing sets
- Train a Logistic Regression classifier using `LogisticRegression`
- Evaluate performance using:
  - Accuracy
  - Precision, Recall, and F1-score
  - ROC Curve and AUC Score
- Visualize results using:
  - Confusion Matrix
  - ROC Curve plot

## Libraries Used
- pandas
- numpy
- seaborn
- matplotlib
- scikit-learn

## Model Summary
Logistic Regression is a statistical model used for **binary classification**. It predicts the probability that an input belongs to a particular class, making it suitable for medical diagnosis, fraud detection, and more.
