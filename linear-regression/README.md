# Linear Regression - AI/ML Learning

This notebook demonstrates a basic implementation of **Linear Regression** using Python and scikit-learn.

## Dataset
- **California Housing Dataset**  
  Contains information such as house age, number of rooms, income, and proximity to the ocean, with the target being `median_house_value`.

## Features of This Notebook

- Load and explore the dataset
- Handle missing values using median imputation
- Encode categorical data using OneHotEncoder
- Scale and preprocess using Scikit-learn Pipelines
- Split data into training and testing sets
- Train a Linear Regression model
- Evaluate performance using:
  - Mean Absolute Error (MAE)
  - Mean Squared Error (MSE)
  - Root Mean Squared Error (RMSE)
  - R² Score
- Visualize results using:
  - Boxplot for feature distribution
  - Histogram for house value analysis

## Libraries Used
- pandas
- numpy
- seaborn
- matplotlib
- scikit-learn

## Model Summary
Linear Regression models the relationship between input features and a continuous target variable by fitting a straight line that minimizes the prediction error.
