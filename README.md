# AI-ML-Models

This repository documents my hands-on learning journey through foundational Machine Learning algorithms using Python and Scikit-learn.

Each notebook includes a full workflow — from data preprocessing and model training to evaluation and visualization — using real-world datasets.

## Models Implemented

### Regression
- Linear Regression  
  Predict continuous values using a linear relationship between features.

### Classification
- Logistic Regression  
  Binary classification model for probability-based decision making.

- K-Nearest Neighbors (KNN)  
  Non-parametric method that classifies based on closest training examples.

- Naive Bayes  
  Probabilistic classifier based on Bayes’ theorem.

- Decision Tree  
  Model that learns decision rules from data features.

- Random Forest  
  Ensemble of decision trees to improve accuracy and reduce overfitting.

- Support Vector Machine (SVM)  
  Classification algorithm that finds the best separating boundary between classes.

### Unsupervised Learning
- K-Means Clustering  
  Clustering algorithm that groups data based on feature similarity.

### Dimensionality Reduction
- Principal Component Analysis (PCA)  
  Reduces dimensionality while preserving variance in the data.

## Notebook Workflow

Each model follows a structured pipeline:
- Load and explore the dataset
- Handle missing or categorical values
- Apply scaling where necessary
- Split data into training and testing sets
- Train and evaluate the model
- Visualize results (confusion matrix, scatter plot, etc.)
