# K-Nearest Neighbors (KNN) Classification with Python

This notebook demonstrates a basic implementation of the K-Nearest Neighbors (KNN) algorithm using Python and scikit-learn.

## Dataset
- Iris Dataset (3-class classification problem: Setosa, Versicolor, Virginica)

## Features of This Notebook

- Load and explore the dataset
- Encode categorical labels (if necessary)
- Scale features using StandardScaler
- Split data into training and testing sets
- Train a KNN classifier using KNeighborsClassifier
- Predict and evaluate with:
  - Accuracy
  - Precision, Recall, F1-Score
  - Confusion Matrix
- Visualize:
  - Confusion Matrix (Heatmap)
  - Scatter Plot of 2D feature space

## Libraries Used
- pandas
- numpy
- seaborn
- matplotlib
- scikit-learn

## Algorithm Summary
KNN is a simple, non-parametric algorithm that classifies a point based on the majority class of its nearest neighbors in the feature space.
