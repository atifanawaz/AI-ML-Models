# Naive Bayes - AI/ML Learning

This notebook demonstrates a basic implementation of **Naive Bayes** for text classification using Python and Scikit-learn.

---

## Dataset  
**SMS Spam Collection Dataset**  
A collection of labeled SMS messages classified as either "ham" (not spam) or "spam".

---

## Features of This Notebook
- Load and explore the dataset  
- Convert text labels (`ham`, `spam`) into binary format  
- Convert text data into numeric format using **CountVectorizer**  
- Split data into training and testing sets  
- Train a **Multinomial Naive Bayes** model  
- Evaluate performance using:
  - Accuracy  
  - Precision  
  - Recall  
  - F1 Score  
- Visualize results using:
  - Confusion Matrix Heatmap  
  - Top 20 most frequent spam words (bar chart)

---

## Libraries Used
- pandas  
- numpy  
- matplotlib  
- seaborn  
- scikit-learn

---

## Model Summary
Naive Bayes is a probabilistic classification algorithm based on Bayes' Theorem. It assumes feature independence and is particularly well-suited for text data classification tasks like spam detection.
